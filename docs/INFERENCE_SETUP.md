# Inference runtime

Production uses Nebius Token Factory with NVIDIA Nemotron vision and reasoning, Qwen embeddings and local CPU Whisper transcription. The API's grounded evidence worker and retained editorial agents use the same configured providers and source registry. No Vertex/Gemini SDK or self-hosted GPU is used.

Models and identities are versioned in [production catalog](../config/model-profiles.production.json) and [embedding identity](../config/embedding-identity.production.json). See [configuration](CONFIGURATION.md) for secret delivery. Live calls require `inference_mode=nebius`, the explicit live switch and a real key. Fixtures are accepted only in development and are labelled as such.

Editorial analysis decodes bounded windows from immutable originals, retaining original image dimensions; preview proxies are not model inputs. Frames are sampled at the declared rate and carry timestamps/source labels. Sparse samples cannot establish unseen motion or prove absence between samples. CPU Whisper transcribes bounded 16 kHz audio windows with VAD and records uncertainty. Its presence is not evidence of measured word-error rate.

The live vision endpoint rejects more than eight images in a request. The canonical evidence worker subdivides windows to respect this bound. Editorial requests with more frames retain every sampled image across bounded batches; each batch response is schema-validated before NVIDIA reasoning combines the observations. Any incomplete/invalid batch fails the analysis. Provider aliases and a batch-reasoning pipeline must be evaluated as their own candidate; no quality superiority is inferred.

The grounded API contracts retain source hashes, allowed windows, citations, model configuration, response metadata and review status. Human review determines whether a finding is accepted and whether it becomes a selected timeline range. Re-analysis does not replace a human edit or fabricate a missing shot.

Qwen embedding requests explicitly supply the index dimension (768). Responses are checked for complete batch indices, dimensions, finite values and nonzero norm, then L2-normalized. Corpus and query generation identities must match. Evidence projections enqueue durable vector-index work after normal edits; retries are bounded. Failed/pending indexes return an explicit unavailable/pending result rather than false empty matches. Operators can also invoke `python -m app.evidence.projection --build-vectors PROJECT --live` with the configured private runtime.

Live transport/modality checks and generated-footage analysis are recorded in [cutover evidence](AWS_CUTOVER.md). Comparative movie-quality evaluation remains open. Use `app.inference.cli` with the frozen [evaluation manifest example](../config/evaluation-manifest.example.json), real cleared footage, historical baseline responses and independent annotations. Freeze before tuning and separate recording/setup groups between development and holdout. Fixture scores and schema validity are not accepted as quality evidence. See [quality strategy](QUALITY_STRATEGY.md).

The official [hackathon FAQ](https://nebiusglobalaihackathon.devpost.com/details/faqs) permits unrelated application hosting outside Nebius when the required NVIDIA model is called through Token Factory. Token Factory credits pay for managed inference, not this AWS host or a future studio GPU. Selected NVIDIA model references: [Nemotron 3.5 recipes](https://github.com/NVIDIA-NeMo/Nemotron/blob/main/docs/nemotron/super35/README.md), [Nemotron 3 Super](https://research.nvidia.com/labs/nemotron/Nemotron-3-Super/).
